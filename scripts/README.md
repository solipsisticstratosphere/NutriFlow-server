# Scripts

Утиліти для управління базою даних та запуску тестового сервера.

> **Важливо:** `clear-db.js`, `seed.js` та `full-workflow-test.js` завжди підключаються до `TEST_MONGODB_URI` (`nutriflow-test`), а не до основної бази. Якщо `TEST_MONGODB_URI` не задано або не містить `"test"` — скрипт завершиться з помилкою.

## Файли

```
scripts/
├── clear-db.js              # очищення тестової БД
├── seed.js                  # заповнення тестовими даними
├── full-workflow-test.js    # E2E тест (порт 5001)
└── start-test-server.js    # тестовий сервер на порту 5001
```

```bash
npm run db:clear
```

## E2E workflow тест

```bash
# Термінал 1 — тестовий сервер (порт 5001, nutriflow-test)
npm run test:server

# Термінал 2 — запустити тест
npm run test:workflow
```

**Що тестує `full-workflow-test.js`:**
1. Очищення `nutriflow-test`
2. Запуск seeder
3. Верифікація даних (3 users, 34 products, 3 meals)
4. Логін як Олена
5. Створення продукту через AI (авокадо)
6. Отримання всіх продуктів
7. Створення прийому їжі з кількох продуктів
8. Отримання AI рекомендацій

## start-test-server.js

Запускає основний `server.js` з підміненими змінними:
- `MONGODB_URI` → значення `TEST_MONGODB_URI`
- `PORT` → `5001` (або `TEST_PORT`)

Використовується виключно для `test:workflow`. Основний сервер (`npm start`) завжди використовує `MONGODB_URI`.
